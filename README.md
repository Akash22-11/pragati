# Pragati

**Pragati** is a centralised student activity record platform. Students submit proof of certifications, internships, projects, competitions, and research; faculty and admins review and verify each submission, with QR-based verification and exportable PDF records.

## Features

- **Role-based access** — separate flows for students, faculty, and admins
- **Activity submissions** — students upload certificates/proofs across categories (certification, internship, project, competition, research, extracurricular, other)
- **Verification workflow** — faculty/admin approve, reject, or return submissions, each generating a tamper-evident verification hash
- **QR code verification** — every verified record gets a scannable QR code for instant authenticity checks
- **PDF generation** — export verified activity records as PDFs
- **Real-time notifications** — Socket.IO-powered updates when a submission's status changes
- **File uploads** — Cloudinary-backed storage for certificates and attachments
- **Analytics dashboard** — track submission volumes and verification stats
- **Email notifications** — automated emails on key status changes

## Tech Stack

**Backend**
- [FastAPI](https://fastapi.tiangolo.com/) (Python)
- SQLAlchemy + Alembic (PostgreSQL)
- JWT auth (`python-jose`, `passlib`)
- Socket.IO for real-time updates
- Cloudinary for file storage
- ReportLab + `qrcode` for PDF/QR generation
- Pandas/OpenPyXL for data export

**Frontend**
- HTML, CSS, vanilla JavaScript

**CI/CD**
- GitHub Actions (backend CI, PR checks, security scanning, deployment)

## Getting Started

### Prerequisites
- Python 3.10+
- PostgreSQL

### Backend Setup

```bash
cd backend
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

Create a `.env` file in `backend/` with:

```env
DATABASE_URL=postgresql://user:password@localhost:5432/pragati
JWT_SECRET=your-secret-key
CLOUDINARY_CLOUD_NAME=your-cloud-name
CLOUDINARY_API_KEY=your-api-key
CLOUDINARY_API_SECRET=your-api-secret
MAIL_EMAIL=your-email@example.com
MAIL_PASSWORD=your-app-password
ADMIN_EMAIL=admin@example.com
```

Run migrations and start the server:

```bash
alembic upgrade head
uvicorn main:app --reload
```

The API will be available at `http://localhost:8000`, with interactive docs at `http://localhost:8000/docs`.

### Frontend Setup

The frontend is static HTML/CSS/JS — serve it with any static server, e.g.:

```bash
cd frontend
python -m http.server 5500
```

Then open `http://localhost:5500`.

## API Overview

| Route | Description |
|---|---|
| `/auth` | Registration, login, token refresh |
| `/submissions` | Create, list, and verify student submissions |
| `/profile` | User profile management |
| `/notifications` | Real-time and stored notifications |
| `/uploads` | File upload handling (Cloudinary) |
| `/pdf` | Generate PDF records |
| `/health` | Health check |

Full interactive API docs are auto-generated by FastAPI at `/docs`.
